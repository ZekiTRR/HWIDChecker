Проект написанный на C# для изучения, в котором реализованы алгоритмы для сбора определённой информации о вашей переферии (которую могут использовать системы для сбора HWID'a)

# Функционал:
- Сбор серийника диска (пока что только одного указанного диска)
- Сбор MAC адресов со всех сетевых адаптеров
